# ProxyDrop — бот для продажи недорогих проверенных прокси

Бот сам тянет список прокси с hproxy.com, **проверяет каждый реальным запросом**, хранит в базе и продаёт за USDT через @CryptoBot. Цена по умолчанию — 1 USDT за прокси.

**Как это работает**

1. Каждые 10 минут бот загружает список с `hproxy.com/api/proxy-list` (открытый API без ключа) и добавляет новые прокси в базу.
2. Каждую минуту проверяет пачку: новые, устаревшие живые, а мёртвые — с паузой. Проверка — запрос на ipify через прокси; прокси, которые не скрывают IP сервера, отбрасываются.
3. Покупатель выбирает тип → страну → количество, получает счёт в CryptoBot.
4. После оплаты бот **ещё раз проверяет** кандидатов и выдаёт только живые. Один и тот же прокси одному человеку дважды не продаётся.
5. В течение 60 минут покупатель одной кнопкой меняет нерабочие (один раз на заказ). Это снимает почти все споры.

## 1. Подготовка

- **Токен бота** — @BotFather → `/newbot`. Аватарка: `/setuserpic` и файл `assets/logo.png`.
- **Токен Crypto Pay** — @CryptoBot → Crypto Pay → Create App → API Token. Для тестов: @CryptoTestnetBot и `CRYPTOPAY_TESTNET=true`.
- **Твой Telegram ID** — @userinfobot. Нужен для `ADMIN_IDS` (команды `/stats`, `/refresh`, `/gift`, уведомления об оплатах).
- Добавь бота администратором канала `@EIiteProxy`, чтобы Telegram разрешал проверять подписку пользователей.

## 2. Проверь источник перед деплоем

```bash
pip install -r requirements.txt
python selftest.py
```

Покажет, что отдал источник, как распарсился формат и сколько из первых 40 прокси реально работают. Формат JSON-ответа hproxy я не мог проверить вживую, поэтому парсер терпимый, а при неудаче бот сам берёт txt-списки по каждому протоколу. Если `selftest` показывает 0 записей, пришли мне его вывод.

## 3. Деплой на Render

1. Создай **PostgreSQL** (New → PostgreSQL) и скопируй **Internal Database URL**. Без Postgres на SQLite база стирается при каждом деплое, и ты потеряешь заказы.
2. Залей папку в GitHub-репозиторий.
3. New → **Web Service** → репозиторий. Build: `pip install -r requirements.txt`, Start: `python main.py` (или New → Blueprint, там уже есть `render.yaml`).
4. В Environment добавь: `BOT_TOKEN`, `CRYPTOPAY_TOKEN`, `ADMIN_IDS`, `DATABASE_URL`. Остальное — по желанию (см. `.env.example`).
5. Webhook бот ставит сам по `RENDER_EXTERNAL_URL`. Открой бота и нажми `/start`, потом отправь ему `/refresh` — первая загрузка и проверка займут пару минут.

**Про бесплатный тариф Render.** Бесплатный web-сервис засыпает без входящих запросов. В репозитории есть GitHub Actions-пингер, который обращается к `/health` каждые 5 минут. Чтобы включить его, после загрузки проекта в GitHub открой **Settings → Secrets and variables → Actions → Variables**, создай переменную `RENDER_HEALTH_URL` со значением `https://<твой-сервис>.onrender.com/health`, затем проверь запуск во вкладке **Actions → Keep Render awake → Run workflow**. Пингер должен быть включён на основной ветке репозитория. GitHub может задерживать scheduled-запуски; если нужна большая надёжность, используй платный Render или внешний мониторинг вроде UptimeRobot. Условия бесплатного Postgres на Render проверь в дашборде: у них есть ограничения по сроку.

## 4. Настройки

| Переменная | Что делает |
|---|---|
| `PRICE_PER_PROXY` | цена за один прокси (по умолчанию `1`) |
| `PACK_SIZES` | варианты количества в меню (`1,5,10`) |
| `SAMPLE_SIZE` | бесплатный пример на пользователя, `0` — выключить |
| `REPLACE_MINUTES` | окно замены нерабочих |
| `FRESH_MINUTES` | прокси считается «свежим», если проверен не позже N минут назад |
| `EXTRA_SOURCES` | доп. txt-источники: `socks5\|https://.../list.txt` |

## 5. Что важно знать

- **Подарок.** Администратор может бесплатно выдать прокси командой `/gift <Telegram ID> <количество>`. Получатель должен хотя бы раз запустить бота; выданные прокси появятся в его «Мои заказы».
- **Качество.** Списки поступают из бесплатных источников, поэтому скорость и доступность прокси могут меняться; часть адресов может не работать с отдельными сайтами. Замена нерабочих встроена.
- **Условия использования.** В `/start` указан запрет на мошенничество и спам. Не убирай эту строку.
- **Страны** берутся из JSON-ответа. Если сработал запасной txt-режим, страны неизвестны, и фильтр по стране будет пустым — остаётся «любая страна».
- **Деньги.** Заказ считается оплаченным, только когда счёт в CryptoBot имеет статус `paid`, а сумма и валюта совпали с заказом. Дважды оплаченный счёт даёт одну выдачу.
